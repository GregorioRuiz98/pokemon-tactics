# Prueba de la campaña completa

Usa una nueva aventura o actualiza entre encuentros. Anota semilla, inicial, versión y resolución. El objetivo es comprobar decisiones, lectura y ritmo; no hace falta explicar las reglas básicas de Pokémon al jugador.

| Tramo | Comprobar |
| --- | --- |
| Paleta–Brock | Preparación sin ayuda, identidad de los cuatro mapas, dos accesos al gimnasio y comprensión de alturas/obstáculos. |
| Monte Moon–Misty | Objetivo de mecanismos, elección entre rutas, espacios estrechos y equipo antes del gimnasio. |
| S. S. Anne–Surge | Líneas de tiro, posiciones expuestas y velocidad de las animaciones. |
| Lavanda–Erika | Árboles, visibilidad, estados, manantiales y alternativas a una estrategia estática. |
| Rocket–Koga | Control de mecanismos, Fuji, capacidad de preparar un equipo para el siguiente combate real. |
| Silph–Sabrina | Destinos de transportadores, altura y claridad con seis enemigos. |
| Canela–Giovanni | Alternativas de entrada, identidad de ambos gimnasios y cobertura de tipos. |
| Liga y rival | Preparación entre combates, legibilidad de áreas y necesidad de cambiar de plan. |
| Aves–Mew/Mewtwo | Orden de ambos desafíos, lectura con varias amenazas y cierre de campaña. |

En cada tramo anota duración aproximada, rondas, bajas, qué decisión resultó interesante y dónde tuviste que buscar información. Si repites tres rondas haciendo lo mismo, describe la situación y conserva el guardado. No se exige un tiempo de combate concreto sin observar antes a jugadores reales.

Comprueba también: cerrar y continuar en preparación y combate; cargar tras varias horas; cambiar1×/2×; jugar solo con teclado; texto150%/alto contraste; sonido/movimiento reducido; archivo copiado a una carpeta limpia y arranque sin Godot instalado. Indica expresamente si fue otro equipo físico.

Plantilla de observación: `Versión | Semilla | Inicial | Zona | Objetivo entendido | Decisión | Rondas/minutos | Problema | Guardado/captura`.

Este documento prepara la prueba. No implica que se haya realizado ni autoriza contactar con terceros o publicar el juego.
