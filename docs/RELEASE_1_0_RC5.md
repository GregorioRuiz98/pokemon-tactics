# 1.0.0-rc.5 — informes de jugadores

Acceso a **Errores y sugerencias** desde Inicio y Menú · F1. Formulario con vista previa, datos de versión y contexto opcional; copia, archivo .txt y borrador de correo. El correo de destino no se muestra en los menús. El jugador decide qué compartir y realiza el envío desde su aplicación de correo.

Sin servidor ni envío automático. Para informes largos se usa el portapapeles o el adjunto .txt; guardar el informe funciona sin conexión. [Instrucciones](FEEDBACK.md).
